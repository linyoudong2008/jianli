# 设计规范 · 「温润杂志风」设计系统

> 本文档定义个人在线简历的视觉风格语言与使用规则，所有界面元素遵循同一套令牌（Design Tokens）。
> 令牌定义位置：`css/style.css` 顶部 `:root` 区域。

---

## 一、风格定位

| 关键词 | 说明 |
|---|---|
| 温润 | 暖白纸感基底 + 低饱和点缀色，拒绝高对比科技感 |
| 杂志感 | 刊头式首屏（眉题 → 衬线大字 → 定位语）、细分割线、克制的排版层级 |
| 手作气质 | 姓名下的马克笔高亮、点缀色短横线记号，呼应"手动创作"的个人特质 |

---

## 二、色彩系统

### 1. 中性色阶

| 令牌 | 色值 | 用途 | 对比度（白底） |
|---|---|---|---|
| `--bg` | `#F8F5F0` | 页面基底暖白 | — |
| `--card-bg` | `#FFFFFF` | 卡片 / 弹窗底色 | — |
| `--ink` | `#2C2C2C` | 正文主色 | 12.9:1 ✅ AAA |
| `--ink-soft` | `#6E6259` | 副标题、辅助说明 | 5.2:1 ✅ AA |
| `--ink-faint` | `#9A8E84` | 弱化装饰性文字（≥13px） | 3.2:1，仅限装饰 |
| `--line` | `#E9E2D9` | 分割线、描边 | — |
| `--surface-soft` | `#FAF7F2` | 次级面板（文件夹、图库衬底） | — |
| `--surface-hover` | `#F3EEE7` | 按钮悬停底色 | — |

### 2. 品牌主色

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--primary` | `#9C6B3F` 赭杏 | 眉题、图标、悬停强调、键盘焦点描边（5.5:1 ✅ AA） |
| `--primary-soft` | `rgba(232,184,138,.45)` | 姓名马克笔高亮衬底（不承载文字） |

### 3. 卡片点缀色（仅装饰，禁止用于正文文字）

| 卡片 | 色值 | 名称 |
|---|---|---|
| 教育背景 | `#E8B88A` | 杏色 |
| 专业技能 | `#8CB0C9` | 雾蓝 |
| 项目经验 | `#9DBF9E` | 叶绿 |
| 个人特长 | `#C9B8D9` | 淡紫 |
| 兴趣爱好 | `#E8B0C4` | 粉红 |
| 联系方式 | `#C9C0B8` | 米灰 |

### 4. 使用规则

- 文字只用 `--ink`（正文）/ `--ink-soft`（辅助）；`--ink-faint` 只用于装饰性小字
- 点缀色只出现在：卡片顶部色条、图标底、标签底、短横线记号，且一律与白色混合降饱和
- 可点击元素悬停反馈统一走 `--primary` 或点缀色描边；禁用高饱和纯色铺底

## 三、字体与排版层级

### 1. 字体栈（零外部依赖，系统字体保证加载速度与国内可达性）

- 正文与标题：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 展示级大字（仅首屏姓名）：`Georgia, "Songti SC", "SimSun", serif`（衬线体营造杂志刊头感）

### 2. 五级字号体系

| 层级 | 令牌 | 字号 | 行高 | 用途 |
|---|---|---|---|---|
| L1 展示级 | `--fs-display` | clamp(36px, 5vw, 46px) | 1.25 | 首屏姓名 |
| L2 标题级 | `--fs-h2` | 20px（移动 18px） | 1.25 | 卡片标题、弹窗标题 |
| L3 副标题级 | `--fs-sub` | 14px | 1.7 | 副标题、按钮文字 |
| L4 正文级 | `--fs-body` | 15px（移动 14.5px） | 1.7 | 摘要、弹窗正文 |
| L5 辅助级 | `--fs-caption` | 13px | 1.7 | 眉题、标签、图注 |

### 3. 行高与字距规则

- 标题行高 `1.25`（用户建议区间 1.2–1.3）；正文行高 `1.7`——高于建议上限，原因：中文方块字字面满，1.5–1.6 在长段落易显拥挤，中文排版惯例取 1.6–1.8
- 标题字距收紧 `-0.01em`；眉题大字距 `0.22em`；正文微加 `0.01em` 透气
- 段落行长：首屏定位语限宽 `34em`，防止长行降低可读性

## 五、组件状态规范

所有可点击元素（卡片、胶囊、文件夹、关闭按钮、灯箱按钮）统一三态：

| 状态 | 规则 |
|---|---|
| 常态 | 点缀色 / 主色提示身份；阴影取常驻档 |
| 悬停 | 上浮（卡片 -10px、文件夹 -6px、胶囊 -3px）+ 阴影升档 + 描边或色条回应；动效统一 `cubic-bezier(0.34, 1.2, 0.64, 1)` |
| 点击（active） | 回落按压感：translateY(1px) 或 scale(.92) |
| 键盘聚焦（focus-visible） | 2px 主色 / 点缀色描边 + 3px 偏移 |

触控目标：所有可点元素最小 44×44px（导航点、胶囊、返回按钮、弹窗关闭、灯箱按钮均已保证）。

## 六、视觉记号（全站统一的识别元素）

1. **点缀色短横线**：24×3px，出现于每个卡片标题下方、技能列表项前——代表"手作划线"
2. **马克笔高亮**：姓名下半部的杏色衬底，全站唯一一处，保持首屏记忆点
3. **顶部色条**：卡片顶部 3px（悬停增至 5px），色随卡片专属点缀色
4. **分割线**：一律 `1px solid var(--line)`，用于页头底、栅栏顶、页脚顶、弹窗头

---

## 七、响应式断点

| 断点 | 布局 | 要点 |
|---|---|---|
| ≥1024px（桌面） | 卡片 3 列 | 容器最大 1360px，字号完整层级 |
| 768–1023px（平板） | 卡片 2 列 | 其余不变 |
| <768px（移动，最小 320px） | 卡片 1 列 | 内边距 20px、`--fs-h2` 降为 18px、画廊/文件夹单列、灯箱切换按钮移至底部 |

移动端附加规则：无 hover 时预览标签常显；文字流式缩放（clamp）保证 320px 宽无横向滚动；`prefers-reduced-motion` 下关闭全部动效。

---

## 八、动效规范

- 统一缓动曲线：`cubic-bezier(0.34, 1.2, 0.64, 1)`（弹性舒缓）
- 时长：微交互 0.3–0.35s，位移类 0.45–0.5s，弹窗遮罩淡入 0.35s
- 动效仅用于反馈（悬停、开合），无循环装饰动画（scroll-hint 的 2.4s 浮动除外，且随系统减动效设置关闭）

---

## 九、视频组件规范

作品集内的演示视频采用「探测式挂载」：

- 数据位置：卡片 `folders[].video` 字段，值为 `videos/` 下的文件路径（当前约定 `videos/gameplay.mp4`）
- 文件存在：渲染 HTML5 播放器——16:9 预留空间（`aspect-ratio`）、游戏截图作封面（poster）、`playsinline` 移动端内联播放、圆角与阴影与图库统一
- 文件不存在：显示「游戏演示视频 · 即将上线」虚线占位（`.video-slot`），无控制台报错
- 格式要求：mp4（H.264 编码，兼容性最好）；GitHub 单文件上限 100MB，建议压缩至 10–30MB
- 使用方式：录好视频后重命名为 `gameplay.mp4` 放入 `videos/` 文件夹即可，无需改代码
